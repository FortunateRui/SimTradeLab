## 本设计实现中与定义的区别
- 遇到同向setup时，不再判断setup区间是否在之前的setup区间之内，而是直接重新计数。因为交易成功率本来就偏低
- 因为新的setup会直接覆盖之前的setup，所以不会出现Recycle，也不再需要判断setup的延伸。
